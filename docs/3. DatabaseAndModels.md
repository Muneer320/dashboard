# Database & Models

## Database: PostgreSQL (Supabase)

---

## USERS TABLE

Fields:

- id (UUID)
- unstop_id
- username
- password_hash
- name
- details (JSONB)
- events (JSONB)
- food (JSONB)
- access_level (ENUM)
- role
- is_profile_complete

---

## DETAILS STRUCTURE

Contains:

- email
- phone
- college
- year
- branch
- profile_pic
- city
- emergency_contact

---

## EVENTS FIELD (CRITICAL)

Structure:

{
  eventId: {
    phase: number
    status: "active/completed/eliminated"
    accessLevel: "ROUND1/FINAL/FULL"

    submission: boolean
    submissionType: "url/file"
    submissionURL: string
    submissionFile: string

    submissionTime: timestamp

    score: number
    rank: number
  }
}

## IMPORTANT DESIGN DECISION

Denormalization is intentional.

Why:
- Fast reads
- Simpler queries

Rule:
Always update both sides.
