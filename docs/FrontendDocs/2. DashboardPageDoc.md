# Dashboard Page — Detailed Frontend Specification

## 1. Purpose

The Dashboard is the **user’s control center**.

It provides:
- Overview of registered events
- Current progress/status in events
- Quick navigation into active events

It is NOT meant to:
- Show all events (that’s /events)
- Handle submissions directly (redirect to event page)

---

## 2. Route

/dashboard

---

## 3. Data Requirements

### API

GET /users/:id/events

### Expected Data Shape

{
  "eventId1": {
    "phase": 1,
    "status": "active/completed/eliminated",
    "accessLevel": "ROUND1/FINAL/FULL",
    "submission": true,
    "score": 50,
    "rank": 12
  }
}

## 6. Event Card Component

## Component: <EventCard />

---

### Props

{
  eventId: string
  name: string
  phase: number
  status: string
  accessLevel: string
  submission: boolean
}

---

### UI Elements

- Event Name
- Phase Badge (Phase 1 / Phase 2)
- Status Badge:
  - Active
  - Completed
  - Eliminated

- Submission Status:
  - "Submitted" / "Pending"

- CTA Button:
  → "Go to Event"

---

### Behavior

Click → redirect:
/events/[eventId]

---

## 7. Conditional UI Logic (CRITICAL)

---

### Case 1: Active Event

- Highlight card
- CTA enabled

---

### Case 2: Completed Event

- Muted styling
- CTA still enabled

---

### Case 3: Eliminated

- Show "Eliminated"
- CTA still allowed (view only)

---

### Case 4: Submission Done

- Show "Submitted" badge

---

### Case 5: No Events

- Show empty state:
  "You have not registered for any events yet"

---

## 12. Styling Guidelines

- Use consistent spacing (gap-4 / gap-6)
- Cards should be:
  - Rounded
  - Slight shadow
  - Hover effect

- Status colors:
  - Active → Green
  - Completed → Gray
  - Eliminated → Red

---

## 13. Performance Considerations

- Cache events data
- Avoid refetch on every navigation
- Use memoized components

---

## 14. Edge Cases

- No events → empty state
- API failure → error UI
- Partial data → fallback values

---

## 15. Definition of Done

Dashboard is complete if:

- Events load correctly
- Navigation works
- Status + submission reflected correctly
- Loading + error states handled
- Matches Figma layout
