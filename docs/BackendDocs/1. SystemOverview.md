# System Overview

## Purpose

The User & Event Dashboard is the central orchestration system for the Ascent Techfest. It manages user identity, event participation, submissions, access control, and QR-based validation.

This system is tightly integrated with Unstop for user onboarding and serves as the unified interface for all participants.

---

## Core Responsibilities

1. User Identity Management
2. Event Lifecycle Management
3. Submission Handling
4. Access Control Enforcement
5. QR-based Validation (Food + Event Entry)

---

## Design Philosophy

- Backend-driven logic (frontend is thin)
- Per-event scoped access control
- Intentional denormalization for performance
- Real-time ready architecture

---

## High-Level Flow

1. User registers on Unstop
2. Backend sync creates/updates user
3. User logs in with credentials
4. Dashboard loads user + events
5. User interacts with events
6. All actions reflect in DB (bi-directional updates)
7. QR system validates real-world interactions

---

## Key Concepts

### 1. Per-Event Access Control
Access is NOT global. Each event defines:
- What user can see
- What user can do

### 2. Phase-Based System
Events are divided into phases:
- Phase 1 (Qualifier)
- Phase 2 (Final)

### 3. Dual Data Model
- users.events → user-centric view
- events.participants → event-centric view

Both must always stay in sync.

---

## System Boundaries

### This system handles:
- Users
- Events
- Submissions
- QR validation

### This system DOES NOT handle:
- Mirage logic
- Sidequest engine
- Campus tour logic

(Only integrates with them if needed)

## Performance Expectations

- API < 200ms
- QR validation < 300ms
- Concurrent users: 1000+
