# Mirage processor testing source

The original test harness exercised image matching, worker/server behavior, database calls and telemetry for the Mirage subsystem. Its retained `test_*.py` modules are historical implementation evidence; this archive does not claim a completed processor or biometric accuracy evaluation.

Identity manifests, operational account data, private configuration and dataset-download scripts have been removed. No face dataset is included, downloaded or processed for archival verification. A future fork should design isolated tests with synthetic inputs and obtain appropriate rights and consent before using real imagery.

The processor test suite was not run as part of this source-only publication. The verified public frontend preview and the backend/migration limitations are listed in the [archive notes](../../ARCHIVE_NOTES.md). Preserve the Mirage team's attribution and the original contributor history in the [main README](../../README.md).
